# Claude Code アドオン

Claude Code の「フック」機能で、出来事が起きるたびに AgentWingman へ知らせます。

| Claude Code の出来事 | キャラクター |
|---|---|
| 依頼を送った | 思考中（パネルに依頼文） |
| ツールを実行中 | 作業中（パネルに `Bash: npm test` など） |
| 許可を求めている | **承認待ち**（手を振る＋音） |
| 入力を待っている・質問している | **質問があります** |
| 応答が終わった | **タスク完了**（最後の返答をパネルに） |
| エラーで止まった（利用上限など） | **エラー** |
| コンテキスト圧縮 | 汗をかく（一回） |
| サブエージェント開始・終了 | 「出撃！」「帰還」の吹き出し |

複数の Claude Code を同時に動かしていても、セッションごとに覚えています。
誰かが呼んでいればそのセッションを、そうでなければ最後に動いたセッションを表示します。
パネル左上は `CC`（ほかにもセッションがあれば `CC +2` など）、モードの欄にはプロジェクトのフォルダ名が出ます。

## 使い方

1. トレイ → アドオン → **Claude Code** にチェック
2. トレイ → アドオン → **Claude Code のフック → 登録する…**（一度だけ。確認画面が出ます）
3. Claude Code を起動し直す（すぐ反映されることもあります）

コマンドで登録する場合（Node.js が必要）:

```bash
node "<AgentWingman のフォルダ>\addons\claude-code\install-hooks.js"
```

Node.js が入っていない PC では、トレイから登録すると `AgentWingman.exe --agent-wingman-hook` を
Claude Code の「exec 形式」（シェルを使わない形）で登録します。Git Bash でも PowerShell でも動きます。

`~/.claude/settings.json`（全プロジェクト共通の設定）に 13 種類のフックが追加されます。変更前に同じ場所へ
`settings.json.bak-agent-wingman-日時` というバックアップを作ります。もう一度実行しても重複しません。
既存の設定やほかのフックには触れません。

外すとき: トレイ → アドオン → Claude Code のフック → 外す…（またはコマンドに `--uninstall` を付ける）

## しくみと安全性

- 登録されるのは `node ".../hook.js"` という **非同期（async）** のフックです。Claude Code の動作を待たせません。
- `hook.js` は受け取った内容を `127.0.0.1:8766`（このPCの中だけ）へ送るだけで、何も出力せず、常に正常終了します。
  そのため Claude Code の判断や会話の内容には一切影響しません。AgentWingman を起動していないときは何もせずに終わります。
- 送られる内容には、依頼文・ツールの引数・最後の返答が含まれます。外部には送りません。
- ポートを変えたときは、`config.json` の `addons.claude-code.settings.port` と、環境変数 `AGENT_WINGMAN_PORT` を同じ値にしてください。
