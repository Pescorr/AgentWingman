# 画像生成 AI 用プロンプト

ChatGPT（画像生成）、Gemini、Copilot など、**画像を添付して指示できる AI** 向けです。

## 基本の流れ

1. まず `idle.png` を作る（ほかのポーズの基準になるので、納得いくまでやり直す）
2. 残りのポーズは、**できあがった idle.png も一緒に添付**して「この画像と同じ大きさ・同じ位置で」と頼む
3. 背景が透明にならなかったら、緑のベタ塗りにしてもらい `skin.json` の `chromaKey` で抜く

---

## 共通プロンプト（毎回最初に貼る）

> 添付する1枚目は私のオリジナルキャラクターです。2枚目はポーズの見本です。
> 1枚目のキャラクターを、2枚目の見本と同じポーズ・同じ向き・同じ構図で描いてください。
>
> 条件:
> - 出力は 512×512 の正方形の画像を1枚
> - 背景は透明。透明にできない場合は #00FF00 の単色ベタ塗り（グラデーション・模様・影を入れない）
> - キャラクターは全身。足元を画像の下端中央に置き、頭のてっぺんは上から1割ほどの位置
> - 2〜2.5頭身のデフォルメ、はっきりした太めの輪郭線、フラットな塗り（デスクトップの小さなマスコットとして見やすく）
> - 髪型・服装・配色・特徴は1枚目のキャラクターに忠実に
> - 床の影、背景の小物、文字、「！」や星や汗などの記号は描かない
> - キャラクターの色に #00FF00 に近い緑を使わない（背景を抜くため）

2ポーズ目以降は、次の1行を足します。

> 3枚目の画像（すでに作った idle.png）と、キャラクターの大きさ・位置・画風を完全にそろえてください。

## ポーズ別の指示（共通プロンプトのあとに続ける）

| 出力ファイル | 見本 | 追加する指示 |
|---|---|---|
| `idle.png` | `guide/idle.png` | 正面を向いて自然に立つ。腕は下ろす。目は開いて穏やかな表情。 |
| `blink.png` | `guide/blink.png` | idle と全く同じ姿勢・表情で、目だけを閉じる。 |
| `read.png` | `guide/read.png` | idle と同じ姿勢で、目線だけを画面の右に向ける（文章を読んでいる感じ）。 |
| `think.png` | `guide/think.png` | 目線を右斜め上に向け、考えごとをしている表情。姿勢は idle とほぼ同じ。 |
| `type1.png` | `guide/type1.png` | 胸の前にある小さなキーボードを両手で打っている。画面左側の手は下、右側の手は少し上。 |
| `type2.png` | `guide/type2.png` | type1 と同じで、左右の手の上下を入れ替える。 |
| `question.png` | `guide/question.png` | 画面右側の手を高く挙げ、こちらを呼んでいる表情。 |
| `wave1.png` | `guide/wave1.png` | 画面右側の手を肩の高さで外側に開き、手を振っている。 |
| `wave2.png` | `guide/wave2.png` | wave1 と同じで、振っている手が頭のほうに倒れた位置。 |
| `cheer.png` | `guide/cheer.png` | 両手を上げてバンザイ。目を細めて嬉しそうに。 |
| `error.png` | `guide/error.png` | 困った・焦った表情（目を > < にする、眉を下げる等）。姿勢は idle とほぼ同じ。 |
| `sleep.png` | `guide/sleep.png` | idle と同じ姿勢で、目を閉じて静かに休んでいる。 |

## 全ポーズを1枚で頼む場合

一度に描かせたいときは、見本に `guide/_all_poses.png` を添付して次のように頼みます。
（AI によってはマスがずれやすいので、うまくいかなければ1枚ずつのほうが確実です）

> 添付する1枚目は私のオリジナルキャラクターです。2枚目は12ポーズの見本シートです。
> 1枚目のキャラクターで、2枚目と同じ並び（4列×3行、各マス同じ大きさ）・同じポーズのスプライトシートを描いてください。
>
> 条件:
> - 画像全体は 2048×1536、各マスは 512×512 で、マスの境界線・文字・ラベルは描かない
> - 背景は全体を #00FF00 の単色ベタ塗り
> - すべてのマスでキャラクターの大きさ・足元の位置をそろえる（足元は各マスの下端中央）
> - 2〜2.5頭身のデフォルメ、太めの輪郭線、フラットな塗り
> - 髪型・服装・配色は1枚目に忠実に。影・記号・文字は描かない
>
> 並び（左上から右へ）: 通常 / まばたき / 横目 / 考え中 / タイピング1 / タイピング2 /
> 片手を挙げて呼ぶ / 手を振る1 / 手を振る2 / バンザイ / 困った顔 / 目を閉じて休む

シートの使い方は `README.md` の「1枚のスプライトシートにまとめる」を見てください。

## うまくいかないとき

| 症状 | 対処 |
|---|---|
| 枚ごとにキャラクターの大きさが違う | idle.png を毎回添付して「大きさをそろえて」と念押し。小さなずれは skin.json の `scale` / `x` / `y` で補正 |
| 背景の緑が縁に残る | `chromaTolerance` を 100〜120 に上げる |
| キャラクターの一部（緑の服など）が消える | `chromaTolerance` を下げる。または背景色をマゼンタ `#FF00FF` にして描き直し、`chromaKey` も合わせる |
| 背景に影やグラデーションが入る | 「背景は完全な単色ベタ塗り、影なし」と繰り返す |
